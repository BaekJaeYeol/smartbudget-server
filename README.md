# SmartBudget 서버
FastAPI 기반 사용자 등록·로그인·JWT 갱신·본인 계정 조회 및 수정 API입니다. SQLite와 SQLAlchemy를 사용하며 로컬 `.env`와 시스템 환경 변수로 설정합니다.

- [프로젝트 문서 안내](docs/index.md)
